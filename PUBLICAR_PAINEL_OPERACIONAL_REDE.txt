───────────────────────────────────────────────────────────────
 STREAMLIT CLOUD (recomendado — link HTTPS, funciona no celular)
───────────────────────────────────────────────────────────────

1) GitHub: repositório lubrificacaomaquinassv-cloud/apontamento_campo
   (ou um repo só “painel-campo-operacional”)

2) Subir estes arquivos da pasta ATUALIZACAO_APONTAMENTO_CAMPO:
   · painel_operacional.py          ← Main file no Streamlit Cloud
   · pwa_medidas.py
   · sigcf_auth.py
   · sigcf_theme.py
   · requirements.txt
   · pasta assets/ (logo)
   · pasta .streamlit/config.toml

3) https://share.streamlit.io → New app
   · Repo + branch
   · Main file path: painel_operacional.py
   · Secrets: copiar SUPABASE_URL e SUPABASE_KEY do app antigo
   · APP_PIN vazio ou o PIN da controladoria

4) URL gerada (exemplo):
   https://painel-campo-xxxx.streamlit.app
   Essa URL abre em qualquer rede, PC, tablet ou celular.
